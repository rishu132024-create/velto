# Velto Programming Language

## Vision

Velto is a general-purpose programming language designed to make software development accessible, powerful, and productive.

## Main Goal

Build a programming language and ecosystem capable of supporting the major areas where Python is used.

## Core Components

1. Velto Lexer
2. Velto Parser
3. Velto AST
4. Velto Runtime
5. Velto Standard Library
6. Velto Package Manager
7. Velto Compiler
8. Velto Developer Tools

## Architecture Principles

- Keep the language syntax consistent.
- Keep internal implementation hidden from ordinary users.
- Design reusable standard library APIs.
- Support third-party packages.
- Build reliable cross-platform tools.
- Prefer secure defaults.
- Maintain backward compatibility.

## Development Roadmap

Phase 1: Stabilize the language core.

Phase 2: Improve the runtime and standard library.

Phase 3: Complete package management.

Phase 4: Build Web and API frameworks.

Phase 5: Build Telegram bot framework.

Phase 6: Build application development frameworks.

Phase 7: Develop AI, data, scientific and game libraries.

Phase 8: Complete compiler and developer tools.

Phase 9: Build a professional IDE and online playground.

Phase 10: Grow the community and ecosystem.

## Long-Term Vision

Velto aims to become a practical general-purpose programming language for beginners, students, developers and organizations.
