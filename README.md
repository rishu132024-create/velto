Velto

Velto is a simple, modern, and beginner-friendly programming language.

«🚧 Velto is currently in early development.»

✨ Features

- 🟢 Simple syntax
- 🟢 Beginner-friendly
- 🟢 Variables
- 🟢 Basic arithmetic
- 🟢 "say" command for output
- 🟢 ".vlt" source files
- 🟢 Written with Python
- 🟢 Open source

🧑‍💻 Example

say "Hello World!"

name = "Velto"
say name

x = 10
y = 20

say x + y
say x * y

Output:

Hello World!
Velto
30
200

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/velto.git
cd velto

2. Run a Velto program

python velto.py examples/hello.vlt

Velto will eventually have an online playground where users can write and run Velto programs directly from their browser.

## Installation

Install Velto with pip:

python -m pip install velto-lang

Then check the installation:

velto --version

Run a Velto program:

velto hello.vlt

See INSTALL.md for Linux, macOS, Windows, and Android instructions.
