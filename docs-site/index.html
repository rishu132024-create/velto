Getting Started

Velto is a programming language designed around simple and readable syntax. 

name = "Velto"
say name

Syntax

Velto uses indentation to organize blocks. 

if name == "Velto":
    say "Hello"

Variables

name = "Velto"
version = 1
active = True

say name
say version
say active

Conditions

age = 18

if age >= 18:
    say "Adult"
else:
    say "Minor"

Loops

numbers = [1, 2, 3]

for number in numbers:
    say number
count = 0

while count < 3:
    say count
    count = count + 1

Functions

func hello:
    say "Hello from Velto"

hello()

Collections

List

numbers = [10, 20, 30]
say numbers[0]

Dictionary

user = {
    "name": "Velto",
    "version": 1
}

say user["name"]

Tuple

data = ("Velto", 2026)

say data[0]

Modules

import math

say math.add(10, 20)

Standard Library

Velto provides standard library foundations for mathematics, JSON, files, dates, HTTP, random values and data structures. 

say sqrt(25)
say random()

text = json_stringify({
    "name": "Velto"
})

say text

Web Development

Velto includes foundations for HTTP servers, web applications, templates and REST APIs.

Game Development

Velto includes foundations for sprites, animation, collision, physics, input and sound.
