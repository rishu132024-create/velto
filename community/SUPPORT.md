# Velto Support

## Bug

If something is not working correctly, create a GitHub Issue.

Include:

- Velto version
- Operating system
- Minimal example
- Error message
- Expected behavior
- Actual behavior

## Question

For questions about using Velto, use GitHub Discussions when available.

## Feature Idea

Describe:

- What you want
- Why it is useful
- A small example of how the feature could work

## Security Problem

Do not publish secrets or sensitive information in an issue.

Contact the project maintainers through the appropriate private channel.

## Before Asking

Check the documentation.

Check the tutorials.

Check existing issues.

Check existing discussions.
