# Contributing to Velto

Thank you for helping improve Velto.

## Ways to Contribute

You can contribute by:

- Fixing bugs
- Adding language features
- Improving documentation
- Creating examples
- Writing tests
- Improving developer tools
- Creating libraries
- Improving the website
- Improving the playground
- Reporting problems

## Development

Clone the repository:

git clone https://github.com/rishu132024-create/velto.git

Enter the project:

cd velto

Run a Velto program:

velto hello.vlt

## Code Changes

Keep changes focused.

Use clear names.

Avoid unnecessary changes.

Test your changes before submitting them.

## Documentation

Documentation improvements are welcome.

Examples should be simple and easy to understand.

## Pull Requests

Explain what your change does.

Explain why the change is useful.

Include testing information.

## Bug Reports

Include:

- Velto version
- Android or operating system
- Example code
- Expected result
- Actual result

Do not include passwords, tokens, API keys, or other secrets.
