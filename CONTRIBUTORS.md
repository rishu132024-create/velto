# Velto Contributors

Velto is built with contributions from the community.

## Contributors

Contributors will be recognized here as the project grows.

## How to Become a Contributor

You can contribute by:

- Writing code
- Fixing bugs
- Improving documentation
- Creating examples
- Writing tests
- Improving developer tools
- Creating libraries
- Reporting useful bugs
- Suggesting improvements

Every useful contribution helps improve Velto.
